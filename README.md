# Moneta — трекер финансов

Личный трекер доходов и расходов: одно приложение на **iOS, Android и в вебе** (Expo + React Native + react-native-web).

## Возможности

- **Главная** — общий баланс, доходы/расходы за месяц, балансы счетов, прогресс бюджета, топ категорий, последние операции.
- **Добавление операции** — крупная сумма, своя цифровая клавиатура (в вебе можно печатать с клавиатуры: Enter — сохранить, Esc — закрыть), категории, счёт, дата, заметка.
- **История** — группировка по дням, поиск, фильтр расходы/доходы, переключение месяцев.
- **Аналитика** — кольцевая диаграмма по категориям, сравнение с прошлым месяцем, средний расход в день, процент сбережений, графики по дням и за полгода.
- **Профиль** — счета, свои категории (иконка + цвет), валюта, месячный бюджет, тёмная/светлая/системная тема, экспорт в JSON, демо-данные, сброс.
- На широком экране (веб, от 900px) нижняя панель превращается в боковое меню.

Данные хранятся локально на устройстве (AsyncStorage, в вебе — localStorage).

## Запуск

```bash
npm install
npm start          # dev-сервер: отсканируйте QR в Expo Go или нажмите w для веба
npm run web        # сразу в браузере
npm run typecheck
npm run build:web  # статическая сборка в dist/ для любого хостинга (Vercel, Netlify, GitHub Pages)
```

Сборка нативных приложений для сторов — через EAS: `npx eas-cli@latest build -p android` / `-p ios`.

## Структура

```
src/app/            экраны (Expo Router): (tabs)/ — вкладки, transaction/ — редактор, categories, accounts
src/components/     UI-кит, графики, таб-бар, список операций, редактор
src/store/          Zustand-стор с сохранением, типы, категории по умолчанию, демо-данные
src/lib/            форматирование денег и дат, расчёт статистики
src/theme/          палитры (тёмная/светлая), шрифт Manrope
```
